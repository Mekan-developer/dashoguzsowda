# Бесплатный тариф по умолчанию и истечение платного

## Что изменилось

1. **Регистрация.** Новый пользователь сразу получает бесплатный тариф —
   `GET /v1/profile` отдаёт его в `tariff` с первого входа.
2. **Истечение платного тарифа.** Раз в сутки пользователи с истёкшим платным
   тарифом переводятся на бесплатный. Если объявлений или роликов больше, чем
   позволяет бесплатный, самые старые одобренные скрываются:
   `status: "suspended"`.
3. **Продление.** Когда админ подтверждает оплату нового тарифа, скрытое
   возвращается в `approved` на свободные места — сначала самые свежие.
   Повторной модерации нет.

## Новый статус `suspended`

Приходит у объявлений и роликов только владельцу:

- `GET /v1/listings/my`, `GET /v1/videos/my` — фильтр `?status=suspended` тоже
  работает;
- в публичной выдаче, магазине, избранном и по прямой ссылке такого контента нет.

Что показывать: плашку «Скрыто: превышен лимит тарифа» и кнопку «Продлить
тариф» (ведёт на экран тарифов).

Правка `suspended`-объявления (`POST /v1/listings/{id}`) отправляет его на
модерацию (`pending`), только если в лимите тарифа есть место. Иначе — `403`
с текстом `tariff_limit_exceeded`, как при создании. Можно удалить одно из
активных и затем отредактировать скрытое.

## Push

При переводе на бесплатный тариф приходит push:

```json
{ "type": "tariff", "id": "1" }
```

`id` — id нового (бесплатного) тарифа. По тапу — экран тарифов; пока мобилка
не знает `type: tariff`, она открывает `/home` (штатный fallback). В тексте
push — сколько объявлений и роликов скрыто.

## Что сделать мобилке

1. Добавить `suspended` в отображение статуса «Мои объявления» и «Мои ролики».
2. После push `type: tariff` перезапросить профиль и списки «мои».
