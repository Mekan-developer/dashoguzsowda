# Весь контент — только с токеном

## Что изменилось

Приложением пользуются только зарегистрированные: у каждого с регистрации есть
тариф (бесплатный по умолчанию). Поэтому гостевого режима в API больше нет.

**Без токена открыты только три эндпоинта:**

| Метод | URL | Зачем |
|---|---|---|
| `GET`  | `/v1/about` | экран «О нас» из онбординга |
| `POST` | `/v1/auth/send-code` | отправка SMS-кода |
| `POST` | `/v1/auth/verify` | вход / регистрация, выдаёт токен |

**Всё остальное требует `Authorization: Bearer {token}`**, в том числе то, что
раньше было публичным: `banners`, `categories`, `regions`, `complaint-reasons`,
`news`, `stores` (список, popular, карточка, товары), `search/popular`,
`listings` (лента, карточка, отзывы), `videos` (лента, карточка, просмотр),
`users/{id}/reviews`. Без токена они отвечают `401`
`{"message": "Необходима авторизация"}`.

## Что сделать в мобилке

- До входа не запрашивать ленту, баннеры, категории и прочий контент —
  только «О нас» и экраны SMS-входа.
- На `401` от любого эндпоинта — выход на экран входа (токен истёк или отозван).
- Локальную «историю поиска гостя» можно убрать: гостя больше нет, история
  живёт на сервере (`/v1/search/recent`).
- Формат ответов не менялся.
