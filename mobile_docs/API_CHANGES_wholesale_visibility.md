# Опт видят только розничные продавцы

Сентябрь 2026. Цепочка поставки теперь такая: **клиент → розничный продавец →
оптовик**. Клиент покупает в рознице, розничный продавец закупается у оптовика.
Полное описание — `BACKEND_API.md`, раздел «Магазины» → «Опт видят только
розничные продавцы».

## Кто что видит

| Кто смотрит | Розничные товары и обычные объявления | Опт |
|---|---|---|
| Гость (без токена) | да | нет |
| Клиент — пользователь без магазина | да | нет |
| Владелец одобренного розничного магазина (`sells_retail`, `approved`, витрина активна) | да | да |
| Владелец магазина на модерации / отклонённого / с погасшей витриной | да | нет |
| Чисто оптовый продавец (`sells_retail = false`) | да | только свои товары |

«Опт» — это оптовая цена и партия, товар только с оптовой ценой и чисто
оптовый магазин целиком.

## Что меняется в ответах для тех, кто опта не видит

- `wholesale_price` и `min_order_qty` приходят `null`, `sells_wholesale` —
  `false` (и в карточке магазина, и в блоке `store` товара).
- Товаров только с оптовой ценой нет в `GET /v1/listings`, в витрине магазина и
  в избранном; `GET /v1/listings/{id}` на них отдаёт `404`.
- Чисто оптовых магазинов нет в `GET /v1/stores` и `/stores/popular`;
  `GET /v1/stores/{id}` и `/stores/{id}/listings` на них — `404`.
- `GET /v1/stores?type=wholesale` и `?trade=wholesale` возвращают пустой список.
- `POST /v1/orders`: клиент всегда платит розничную цену, даже когда набрал
  `min_order_qty`; оптовое предложение в корзине — `422` с сообщением
  «товар недоступен».

## Что делать мобилке

1. **Ничего не фильтровать самим** — бэкенд уже решил, что показывать.
   Плашку «Опт» рисовать, как и раньше, только когда `wholesale_price` не `null`.
2. **Переключатель «Опт / Розница»** на экране магазинов и в витрине
   показывать только тем, кто видит опт. Для остальных вкладка «Опт» всегда
   будет пустой. Признак можно брать по профилю: у пользователя есть магазин с
   `sells_retail = true`, `status = approved`, `is_active = true`.
3. **Поменялся пользователь (вход, выход, магазин одобрили)** — перезапросить
   ленту и магазины: ответы зависят от того, кто смотрит.
4. **Корзина:** товар, который пришёл с `wholesale_price = null`, клиенту
   считать по `price`, как обычный розничный.
