# Опт видят тарифы с can_see_wholesale

Флаг тарифа в админке (Тарифы → «Видит оптовые цены»), не имя плана и не
наличие розничного магазина. `User::seesWholesale()` читает активный тариф.
В профиле и каталоге тарифов поле то же: `can_see_wholesale`.

## Кто что видит

| Кто смотрит | Розница | Опт |
|---|---|---|
| Гость | да | нет |
| Тариф без `can_see_wholesale` | да | нет |
| Тариф с `can_see_wholesale` | да | да |
| Владелец своего товара / магазина | да | свои — всегда |

## Что делать мобилке

1. Не фильтровать опт на клиенте — бэкенд уже отсёк.
2. Вкладку «Опт / Розница» показывать при `tariff.can_see_wholesale == true`
   из `GET /v1/profile` (или из каталога `/v1/tariffs`).
3. После смены тарифа / логина — перезапросить ленту и магазины.
