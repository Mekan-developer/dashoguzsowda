# Bruno-коллекция мобильного API

Запросы ко всем эндпоинтам мобильного API `/api/v1`. Открывается в
[Bruno](https://usebruno.com): **Open Collection** → указать эту папку.

## Окружения

| Окружение | `base_url` | Когда |
|---|---|---|
| `local` | `http://<IP вашей машины>:8000/api` | запросы с телефона или другого устройства в той же сети — адрес тот же, что в `APP_URL` |
| `docker` | `http://localhost:8000/api` | с самой машины, где поднят `docker compose` (nginx проброшен на 8000) |

Сами файлы `environments/*.bru` в git не попадают (`.gitignore`) — у каждого
свой адрес и свой сохранённый `{{token}}`. Поэтому конкретный IP здесь не
указан: подставьте свой (посмотреть — `APP_URL` в `.env` или `ip a`) либо
заведите ещё один файл окружения рядом.

## С чего начать

1. **Auth → Отправить SMS-код** — код в dev-режиме не уходит на телефон,
   а пишется в `storage/logs/laravel.log`.
2. **Auth → Подтвердить код** — токен сам сохраняется в переменную `{{token}}`,
   её подставляют все авторизованные запросы. Новый номер = регистрация,
   существующий = вход, сценарий один.
3. Дальше — любой раздел: без шага 2 они вернут 401.

id в адресах не захардкожены: у каждой базы свои записи, и чужой id даёт
404 «Не найдено». Их заполняют списки — первая запись уходит в переменную:
«Публичная выдача» → `{{listing_id}}`, «Мои объявления» → `{{my_listing_id}}`,
«Магазины» → `{{store_id}}`, лента роликов → `{{video_id}}`, «Мои ролики» →
`{{my_video_id}}`, новости → `{{news_id}}`, «Мои отзывы» → `{{review_id}}`,
«Профиль» → `{{user_id}}`, «Мои заказы» → `{{order_id}}`. Сначала откройте
список, потом карточку или действие.

Chunked-загрузка видео так же прокидывает `{{upload_id}}` из шага Init
в Chunk / Complete / отмену, а «Оформить заказ» — `{{order_id}}` в карточку
заказа и отмену плюс `{{suborder_id}}` (id части заказа) в запросы владельца
магазина.

Запросы `Orders → Магазин — …` идут под токеном **владельца магазина**, а не
покупателя: свой товар заказать нельзя, поэтому папку целиком одним токеном не
прогнать — переключите `{{token}}` перед ними. Список «Магазин — заказы
владельцу» сам обновляет `{{suborder_id}}`, так что accept / decline / complete
можно дёргать и без шага оформления.

Заказ ведёт сам владелец магазина: он принимает его, везёт и отмечает
доставленным, а в админке заказ только отображается. Поэтому и в один заказ
попадает товар только одного магазина.

## Что где

| Папка | Эндпоинты |
|---|---|
| `Auth` | вход по SMS, выход |
| `Profile` | профиль, аватар, смена номера, FCM-токен, свой тариф, каталог тарифов, смена подписки |
| `Preferences` | онбординг, синхронизируемый между устройствами |
| `Search` | история поиска (до 8 запросов) и популярные запросы сайта |
| `Listings` | лента с фильтрами, карточка, создание, правка, поднятие |
| `Videos` | лента, загрузка (одним запросом и по частям), лайк, просмотр |
| `Stores` | витрина популярных магазинов, список с фильтрами (опт/розница, доставка, адрес), карточка, товары магазина, свой магазин (`/v1/my/store`) |
| `Orders` | заказы покупателя (оформление, свои заказы, отмена) и заказы, пришедшие владельцу магазина (`/v1/my/store/orders`, принять / отказаться / доставлено) |
| `Favorites`, `Reviews`, `Complaints` | избранное, отзывы (создание + чтение одобренных со сводкой рейтинга), жалобы |
| `Chat` | переписка с поддержкой + авторизация канала Reverb |
| `News`, `Banners`, `Category`, `Region` | публичные справочники и контент |
| `Health` | проверка живости API |

## Лимиты частоты

| Эндпоинт | Лимит |
|---|---|
| `POST /v1/auth/send-code` | 5/мин (плюс cooldown 60 сек на повторный код) |
| `POST /v1/auth/verify`, смена номера | 10/мин |
| `POST /v1/listings`, `POST|PUT /v1/listings/{id}` | 20/мин |
| `POST /v1/videos` | 10/мин (у chunked-загрузки лимита нет) |
| лайк, просмотр ролика, избранное | 60/мин |
| `POST /v1/chat` | 30/мин |
| `POST /v1/reviews`, `POST /v1/complaints` | 10/мин |
| `POST /v1/orders` | 20/мин |
| отмена заказа, ответ магазина (accept / decline / complete) | 30/мин |

Счётчик Laravel для авторизованного запроса ключуется **по пользователю, а не по
роуту**: все перечисленные лимиты расходуют один общий счётчик токена. На практике
это значит, что серия лайков (лимит 60) может выбить 429 у отзыва (лимит 10) в ту же
минуту. Прогоняя папку целиком, не удивляйтесь 429 на хвосте — подождите минуту.

Каждый запрос несёт `docs` с разбором полей и кодов ответа и `tests` —
их можно прогнать пачкой (**Run** на папке или на коллекции), только
учитывая порядок: создающие запросы зависят от id, созданных ранее.

## Когда правите API

Коллекция — часть контракта с мобильной командой наравне с
[../mobile_docs/BACKEND_API.md](../mobile_docs/BACKEND_API.md). Новый роут в
`routes/api/v1.php` — новый `.bru` рядом с соседями по домену; изменилось
поведение существующего — поправить `docs` и `tests` в том же коммите.
