# Bruno-коллекция мобильного API

Запросы ко всем публичным эндпоинтам `/api/v1`. Открывается в
[Bruno](https://usebruno.com): **Open Collection** → указать эту папку.

## Окружения

| Окружение | `base_url` | Когда |
|---|---|---|
| `local` | `http://192.168.1.226:8000/api` | `php artisan serve --host=0.0.0.0`, запросы с телефона в той же сети |
| `docker` | `http://localhost:8000/api` | поднятый `docker compose` (nginx проброшен на 8000) |

Свой адрес правится в `environments/*.bru` — либо заводится ещё один файл рядом.

## С чего начать

1. **Auth → Отправить SMS-код** — код в dev-режиме не уходит на телефон,
   а пишется в `storage/logs/laravel.log`.
2. **Auth → Подтвердить код** — токен сам сохраняется в переменную `{{token}}`,
   её подставляют все авторизованные запросы. Новый номер = регистрация,
   существующий = вход, сценарий один.
3. Дальше — любой раздел: без шага 2 они вернут 401.

Chunked-загрузка видео так же прокидывает `{{upload_id}}` из шага Init
в Chunk / Complete / отмену.

## Что где

| Папка | Эндпоинты |
|---|---|
| `Auth` | вход по SMS, выход |
| `Profile` | профиль, аватар, смена номера, FCM-токен, тариф |
| `Preferences` | онбординг, синхронизируемый между устройствами |
| `Search` | история поиска (до 8 запросов) |
| `Listings` | лента с фильтрами, карточка, создание, правка, поднятие |
| `Videos` | лента, загрузка (одним запросом и по частям), лайк, просмотр |
| `Favorites`, `Reviews`, `Complaints` | избранное, отзывы, жалобы |
| `Chat` | переписка с поддержкой + авторизация канала Reverb |
| `News`, `Banners`, `Category`, `Region` | публичные справочники и контент |
| `Health` | проверка живости API |

Каждый запрос несёт `docs` с разбором полей и кодов ответа и `tests` —
их можно прогнать пачкой (**Run** на папке или на коллекции), только
учитывая порядок: создающие запросы зависят от id, созданных ранее.

## Когда правите API

Коллекция — часть контракта с мобильной командой наравне с
[../mobile_docs/BACKEND_API.md](../mobile_docs/BACKEND_API.md). Новый роут в
`routes/api/v1.php` — новый `.bru` рядом с соседями по домену; изменилось
поведение существующего — поправить `docs` и `tests` в том же коммите.
