⚙ Настройки подключения

Server URL подставляется автоматически под то, откуда открыта страница (напрямую со шлюза или через /otp на домене). Если страница открыта локальным файлом или с другого порта — впиши адрес шлюза руками, например http://192.168.31.163:3000. OTP_SECRET обязателен: без него сервер рвёт соединение с unauthorized. Это тот же секрет, что в .env сервера и в настройках телефона. Имя события должно совпадать с OTP_EVENT_NAME (сейчас: otp).

⚡ Прямой тест моста (без Laravel)

Напрямую вызывает POST /emit-otp на мосту — без Laravel. Если событие появляется в логе ниже, мост работает. Для полного теста — дёрни POST /api/v1/auth/request-code через Bruno/curl.
